# Connect-X

Connect-X is a student collaboration platform designed to help
college students discover teammates, form teams, and collaborate
on projects.

## Problem Statement

Students often struggle to find teammates with relevant skills,
coordinate team activities, and track project progress.

Connect-X aims to bring teammate discovery and project collaboration
into one platform.

## Planned Core Features

- Student profiles and skill-based discovery
- Team creation and join requests
- Project workspaces and task management
- Team communication
- Hackathon and opportunity discovery

## Tech Stack

- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB
- Real-time communication: Socket.IO

## Project Status

Currently in the initial setup and planning phase.

## Development Goal

Build a functional, deployed MVP by January 30, 2027.
